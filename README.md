# Moosespy's Minigames
Erase your boredom by winning willow from an even more bored moose spy! Play minigames against him and try to win them to earn willow, and see how many games you can last! This moose spy may be a bit cynical, though, cheering whenever you lose...

This is a basic terminal game, to familiarize myself with Python. No AI was used in the making of this project.

The games are:
  1. Random Number Guesser
  2. Antler Cup
  3. Memory Game
  4. Hangman
  5. Dice Craps

Have fun!
